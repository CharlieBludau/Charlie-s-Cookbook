# Charlie's Family Cookbook — Curated Edition

This folder is ready for GitHub Pages. It contains all 131 recipe photos as normal image files.

## Test locally
Double-click `index.html`.

## Publish
Upload **all files and the entire `images` folder** to the root of your GitHub repository. GitHub Pages should deploy from the `main` branch and `/ (root)`.

Favorites, ratings, notes, and view preference are saved in the browser you use. The recipe links and photos are permanent files in this folder.
